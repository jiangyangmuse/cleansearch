## 2 做了什么

1. **URL 历史与标题（B-01）**：新增 `urlState.ts`（`readUrlState`/`searchUrl`/`writeUrl`/`seedHistoryState`/`stateFromHistory`）。`App.tsx` 的新查询、分类切换、翻页改 `pushState`；重试与 `popstate` 还原不写历史；`page` 进 URL（`page=1` 省略）；`popstate` 按 state 标记 `{cs:true}` 还原，非本应用条目回落到地址栏。`document.title` 跟随查询与页码。
2. **移动端工具抽屉（B-02）**：新增 `useMediaQuery` 与 `ToolDrawer`（原生 `<dialog>` + `showModal`）。`<900px` 时右栏不再进文档流，改为 FAB + 底部抽屉；桌面端把 4 个竖排图标按钮改成一行 `role=tab` tabs，面板拿回完整栏宽。
3. **触控基线（B-03）**：`@media (pointer: coarse)` 下头部操作、导航、引擎 chip、分页、收藏按钮 ≥44×44，开关 46×28，辅助字号 ≥12px；`<380px` 品牌只留图标，头部不再折行溢出。
4. **引擎菜单与分组（B-04）**：外部 `pointerdown`、窗口滚动、路由变化都收起菜单；`ENGINE_SECTIONS` 给 `section:null` 补「其他引擎」标题与分隔线；状态点改文字标签（`engineStatusLabel`：可用/冷却 N 分/未知/直达/地区/不可用）。
5. **禁用开关（B-05）**：`default_engines === null` 时显示「继承 SearXNG 默认（N 个）」，逐项开关 `disabled` + 半透明 + 不显示为已选 + `aria-describedby` 说明原因；新增「恢复默认」。
6. **AppShell（B-06）**：新增 `AppShell.tsx`，五页共用 skip link、品牌、导航与正文槽位；头部与正文共用 `--shell-max`/`--shell-pad`；删掉 `.header__link{cursor:not-allowed}`；当前页 `aria-current="page"` 唯一。
7. **工具页（B-07）**：`.state__cmd` 改 `pre-wrap` + `overflow-wrap:anywhere` + `max-height:12em`；token 默认掩码，加显示/隐藏与复制。
8. **标题层级与播报（B-08）**：每页 1 个 `h1`（搜索页视觉隐藏），结果卡标题降为 `h3`，结果数用 `role=status` 播报，风险原因用 `aria-describedby` 关联；顺带修掉 `.metabar__muted`/`.group__hint` 用 `opacity` 弱化导致的 3.24:1 对比度问题。
9. **抽屉的现代写法**：按 [Modern Web Guidance](https://github.com/GoogleChrome/modern-web-guidance-src) 的 navigation-drawer / animate-to-from-top-layer / prevent-page-scroll-under-modal-dialog / platform-controls-dismiss-dialog，补 `@starting-style`+`allow-discrete`+`overlay` 进出场、`overscroll-behavior:contain`（含 `::backdrop`）、`closedby="any"`、`prefers-reduced-motion` 分支。
10. **验收脚本**：新增 `scripts/audit-ui.cjs`（42 项断言 + 截图基线 + 两处 axe 扫描）。

## 5 关键决策

| 决策 | 备选 | 理由 |
| --- | --- | --- |
| URL 写历史用 pushState，重试用 replaceState，popstate 不写 | 全部 replaceState（现状）/ 全部 pushState | 现状无法后退；全 push 会让重试与还原重复入栈。历史条目带 `{cs:true}`，非本应用条目回落地址栏 |
| 右栏窄屏用原生 `<dialog>` 而不是自绘遮罩 | 自写 div + 焦点圈定 | 浏览器自带顶层、惰性背景、Esc 与焦点归还；配合 `closedby="any"` 得到返回手势关闭 |
| 4 个竖排工具按钮改一行 tabs | 保留竖排按钮 | 抽屉里必然横排；统一后桌面面板不再被 55px 按钮列挤到 268px |
| `section:null` 统一归「其他引擎」 | 保持无标题静态分组 | 现状把 Google 等混进「中国大陆可直连」，属事实性误导 |
| 继承 SearXNG 默认时开关不做「已选」显示 | 显示实际默认引擎为已选 | 勾选不可操作还显示为选中，会让人以为改动生效 |
| 对比度问题用纯 `--muted` 而不是加粗/放大 | 提高字号到 14px | 12px 辅助文字是设计基线，改颜色成本最低且保住密度 |
