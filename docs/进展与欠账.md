## 当前进度

**本机单用户主线已交付，可进入目标环境验收与质量校准阶段。** 搜索、书签、正文增强、缓存、一键添加、本机千问与 DeepSeek 总结均已有验收记录；Serper 真实兜底和 RDAP 首轮校准也已完成。

最新一轮代码验收记录为 API **315 项通过**、前端构建通过、PowerShell 冒烟 **16/16**、跨平台 CI 冒烟 **15/15**、OpenAPI 生成正常，见 [RDAP 复核报告](../reports/completed/2026-11-07-1506-rdap-review-calibration.md)。这些是上轮实测证据；本次进度整理仅核对文档、链接与台账，未重跑业务测试。

当前未收口项主要是远端托管 CI、正式 Chrome 与原生书签管理器、Android 真机，以及更广泛的检索和风险样本。下表的“完成”仅指已列明的首版交付范围。

| 中 · P1-2a | 正式 Chrome 与原生书签互迁 | 可用的隔离浏览器配置和可公开的测试书签 | Chrome 开发者模式手动加载扩展，完成 popup/右键收藏；Chrome/Edge/Firefox 原生管理器导出→项目导入→项目导出→原生导入，核对目录/标题/URL/数量及丢失项 |
| 中 · P1-2b | Android 真机闭环 | 真实设备及设备可安全访问的部署地址 | 实际安装、系统分享 URL、标题/地址预填、保存和回查；记录系统/浏览器版本。桌面 `127.0.0.1` 不直接作为手机访问地址 |
| 中 · P1-3a | RDAP 校准与并发验收 | 有出处的新注册正常域名对照集 | 补齐新站误报样本；在当前 30 天/0.15 策略与整批 4 秒预算下，记录跨请求并发、429/超时、覆盖率与延迟，再决定是否调整权重 |
| 中 · P2-A | 扩大真实检索/总结评估 | 固定查询与标注、可用上游及调用预算 | 宿主机/容器用同一批多主题样本，对照期望域名命中、人工相关性、正文覆盖、引用内容、首段及总耗时、失败率与成本；保留原始输出 |

建议执行顺序：远端条件齐备时先跑托管 CI；其余可先补 RDAP 新站对照与多主题评估，再补正式浏览器及 Android。未取得外部条件的项目保留“待验”，不推定通过。
